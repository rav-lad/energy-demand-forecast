\section*{Executive Summary}

\textbf{Objective.}  
This study develops a complete machine learning framework for day-ahead electricity price forecasting on the French market, and evaluates the downstream impact on systematic trading strategies. The objective is to deliver a pipeline suitable for production, from data collection to forecasting, backtesting, validation, and model monitoring.

\textbf{Methods.}  
We evaluate five predictive models (Random Forest, XGBoost, LightGBM, Ridge Regression, GRU) over 700 days of historical data (2023–2024). The framework includes:
\begin{itemize}
    \item feature engineering (lags, rolling statistics, meteorological data, calendar effects),
    \item strict leakage audits,
    \item realistic trading simulation with transaction costs,
    \item Sharpe ratio correction,
    \item robustness checks and extreme-event analysis.
\end{itemize}

\textbf{Key Findings.}
\begin{itemize}
    \item XGBoost achieves the strongest predictive performance ($R^2 = 0.686$, MAPE $\approx 30\%$).
    \item Random Forest yields the best trading performance (Sharpe 1.65, annualized return 88\%, max drawdown -4.2\%).
    \item Tree-based models outperform the GRU due to the tabular, low-sample nature of the dataset.
    \item A critical Sharpe annualization bug inflated results by 62\%; the corrected methodology aligns with institutional standards.
\end{itemize}

\textbf{Production Readiness.}  
A robust pipeline is achieved, with no detected data leakage. For deployment, the following enhancements are recommended:
\begin{itemize}
    \item replacing historical weather observations with forecasts,
    \item adding walk-forward validation,
    \item implementing drift monitoring and automated retraining triggers.
\end{itemize}

\textbf{Conclusion.}  
This framework demonstrates that high-quality electricity price forecasts and profitable trading strategies are attainable using non-deep-learning models, provided the pipeline follows rigorous validation and error controls.

\begin{abstract}
This study presents a complete machine learning framework for forecasting day-ahead electricity prices in the French market and evaluates its application in systematic trading strategies. Five models are benchmarked—Random Forest, XGBoost, LightGBM, Ridge Regression, and a compact GRU network—using 700 days of historical data. XGBoost delivers the highest predictive accuracy ($R^2 = 0.686$), while Random Forest achieves superior risk-adjusted trading performance (Sharpe 1.65, annualized return 88\%). A thorough data-leakage audit and transaction-cost modeling are conducted, and a critical Sharpe annualization bug inflating results by 62\% is corrected. The study provides an interpretable, reproducible, and production-ready methodology for ML-based electricity trading systems.
\end{abstract}

\section{Introduction}

Day-ahead electricity price forecasting plays a central role in energy market operations, guiding bidding decisions, hedging, generation scheduling, and risk management. Compared to traditional financial assets, electricity exhibits unique structural features:

\begin{itemize}
    \item \textbf{Non-storability}: leading to structural volatility and scarcity spikes.
    \item \textbf{Merit order dynamics}: generating strongly nonlinear price–load relationships.
    \item \textbf{Weather dependence}: introducing exogenous uncertainty and forecast error propagation.
    \item \textbf{Regulatory constraints}: reducing market efficiency.
    \item \textbf{Renewable integration}: increasing non-stationarity and forecast dispersion.
\end{itemize}

\subsection{Research Objectives}

This work pursues three goals:

\begin{enumerate}
    \item Build and compare multiple ML models for day-ahead price forecasting.
    \item Evaluate a realistic trading strategy based on model predictions.
    \item Conduct rigorous data-leakage audits ensuring production-grade reliability.
\end{enumerate}

\subsection{Contributions}

\begin{itemize}
    \item End-to-end pipeline: data acquisition, modeling, forecasting, trading evaluation.
    \item Benchmark of 5 ML models including both tree-based and neural approaches.
    \item Correction of a major Sharpe annualization bug (+62\% inflation).
    \item Full leakage audit, ensuring trustworthy performance claims.
    \item Trading results with realistic assumptions (transaction costs, holding limits).
\end{itemize}

\section{Feature Engineering}

\subsection{Temporal Features}

Cyclical encodings:
\[
\text{month}_{\sin}=\sin\left(\frac{2\pi m}{12}\right), \quad
\text{dow}_{\sin}=\sin\left(\frac{2\pi d}{7}\right).
\]

\subsection{Lag Features}

\[
\mathbf{P}_{lag,t} = \{P_{t-1}, P_{t-2}, P_{t-3}, P_{t-7}\}
\]
\[
\mathbf{L}_{lag,t} = \{L_{t-1}, L_{t-2}, L_{t-3}, L_{t-7}, L_{t-14}\}
\]

\subsection{Rolling Statistics}

Windows $w \in \{7, 14, 30\}$:
\[
\mu_{L,w}, \sigma_{L,w}
\]

\subsection{Total Feature Set}

A total of \textbf{45 features}:
\begin{itemize}
    \item 8 temporal
    \item 9 lag-based
    \item 18 rolling statistics
    \item 6 meteorological
    \item 4 derived features
\end{itemize}

\section{Methodology}

\subsection{Train–Test Split}

\begin{itemize}
    \item Train: 560 days
    \item Test: 140 days
    \item Temporal split (no shuffling)
\end{itemize}

\textbf{Critical:} All feature engineering applied \emph{after} the split → no leakage.

\subsection{Models Evaluated}

Five models:

\textbf{Random Forest}.  
100 trees, depth=20.

\textbf{XGBoost}.  
100 estimators, learning rate=0.1, depth=6.

\textbf{LightGBM}.  
Leaf-wise growth, 100 estimators.

\textbf{Ridge Regression}.  
L2 penalty $\alpha=1$.

\textbf{GRU}.  
128 hidden units, 1 layer, dropout 0.1, 14-day lookback.  
\textit{Note: The originally planned TFT model was removed due to incompatible prediction constraints and insufficient data.}

\subsection{Walk-Forward Recommendation}

Although a single temporal split is used, a \textbf{walk-forward expanding-window} should be adopted in future work to:
\begin{itemize}
    \item evaluate long-term stability,
    \item capture regime shifts,
    \item reduce overfitting risk.
\end{itemize}

\section{Discussion and Limitations}

\subsection{Realistic Performance Expectations}

Corrected Sharpe ratios (1.2–1.7) align with quantitative hedge fund benchmarks.  
Electricity markets remain structurally inefficient due to:
\begin{itemize}
    \item weather-driven uncertainty,
    \item non-storability,
    \item merit-order nonlinearity.
\end{itemize}

\subsection{Production Considerations}

Required adjustments:
\begin{itemize}
    \item replace weather observations with forecasts,
    \item add walk-forward validation,
    \item incorporate real-world transaction cost variations,
    \item implement model drift monitoring.
\end{itemize}

\subsection{Limitations}

\begin{itemize}
    \item short dataset (2 years),
    \item single market (France),
    \item limited extreme events in test period,
    \item daily granularity (intraday dynamics lost).
\end{itemize}

%=====================================================================
% CONCLUSION
%=====================================================================
\section{Conclusion}

This study demonstrates that robust, production-ready electricity price forecasting is achievable using tree-based machine learning models. XGBoost provides the best predictive accuracy, while Random Forest produces superior trading performance and risk control. After correcting major methodological issues (notably Sharpe inflation), the resulting pipeline is reproducible, interpretable, and suitable for deployment.
